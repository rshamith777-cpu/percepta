## Status labels (used consistently)
- **IMPLEMENTED** — code/foundation exists in repo.
- **PARTIALLY IMPLEMENTED** — meaningful subset exists; important gaps remain.
- **LOCALLY TESTED** — executed in local/dev/test context with recorded evidence (scope-limited).
- **CONTRACT TESTED** — automated contract/unit/API-handler tests executed and passed for the stated scope (not full E2E/external integration).
- **NOT BROWSER TESTED** — no executed browser/E2E validation for the stated flow in Phase 4 (resource/environment constraints).
- **BLOCKED** — requires external credentials, official access, tooling, deployment authorization, hardware, or runtime state not available/verified.
- **NOT IMPLEMENTED** — no genuine implementation for the claimed capability.
- **NOT VERIFIED** — implementation may exist but required runtime/external/browser evidence not captured.

*An endpoint returning 503/501 is **not** a completed integration.* *Environment-variable placeholders are **not** working credentials/integrations.* *Synthetic robotics/CMMS simulation is **not** real hardware/ERP integration.*
