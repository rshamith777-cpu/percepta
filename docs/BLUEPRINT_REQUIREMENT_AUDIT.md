## Safety invariants (verified/preserved in Phase 3 scope)
- Draft sync endpoint mutates **only** `technicianNotes` and appends `notes_updated` audit with `draftSyncIdempotencyKey`; **never** mutates safety gate decisions, isolation/safe-to-touch fields, diagnosis BLOCK state, maintenance status, `currentVerification`/verification history, `verified_resolved`, escalation, or authorization. **Verified by `draft-sync-safety.contract.test.ts` (1 pass).**
- Deterministic fail-closed safety gate remains authoritative; BLOCK precedence preserved (no changes to gate logic). Blocked integrations cannot affect safety decisions (status/validation endpoints only). BigQuery POST validates but `performed:false`, no ingest.
- Service worker must never cache `/api/*` (unchanged; not re-tested in browser Phase 3).
- No robot commands/dangerous maintenance actions from external integrations.
